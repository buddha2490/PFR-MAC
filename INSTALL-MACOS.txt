PFR Sentinel — macOS install
============================

Requires an Apple Silicon Mac (M1 or newer), macOS 12 or later.


INSTALL
-------

1. Drag PFRSentinel.app onto the Applications folder in this window.

2. IMPORTANT — first launch only:
   Right-click (or Control-click) PFRSentinel in Applications and choose
   "Open", then click "Open" in the dialog.

   A plain double-click will NOT work the first time. macOS blocks apps that
   are not notarized by Apple, and shows a message like "Apple could not
   verify PFRSentinel is free of malware." Right-click -> Open is the
   supported way to bypass that for an app you trust.

   Every launch after the first one works normally.

   If macOS refuses even with right-click -> Open, run this in Terminal:

       xattr -dr com.apple.quarantine /Applications/PFRSentinel.app


USING A ZWO CAMERA
------------------

Plug the camera in before starting the app. The ZWO ASI SDK is bundled — you
do not need to install anything from ZWO, and you do not need Homebrew.

On first capture macOS may ask for permission to access a USB device. Allow it.

If the camera is not detected, open the Capture page and click
"Detect Cameras". The SDK path field can be left as-is; it defaults to the
copy inside the app.


VIEWING THE FEED FROM ANOTHER COMPUTER
--------------------------------------

On the Output page, enable the Web Server. Set the host to the machine's
Tailscale address (run `tailscale ip -4` in Terminal to find it), then browse
from any other device on your tailnet to:

    http://<tailscale-ip>:8080/live

That page auto-refreshes. /latest serves the raw image and /status returns
JSON if you want to script against it.

Note: these endpoints have NO password. Binding the Tailscale address keeps
them on your private network. Setting 0.0.0.0 instead would expose your camera
feed on any Wi-Fi the Mac joins.


TIMELAPSE
---------

ffmpeg is bundled, so timelapse works with no extra install. Enable it on the
Timelapse page and pick an output folder.


WHERE YOUR DATA LIVES
---------------------

    ~/Library/Application Support/PFRSentinel/

That holds config.json, logs, captured images, and the image library.
Deleting that folder resets the app to defaults.
